## N1 

O bloco N1 é composto pelas seguintes atividades focadas na contextualização inicial e modelagem conceitual do projeto:

### 1. Atividade PRJContexto – Especificação do Cenário do Projeto – StoryBoard
* **Descrição:** Definição do cenário de uso do sistema, personas envolvidas, jornada do usuário e representação visual por meio de Storyboard para ilustrar o problema e a solução proposta.
  
### 2. Atividade PRJModDominio – Especificação do Modelo de Domínio
* **Descrição:** Construção e especificação do Modelo de Domínio do sistema, identificando entidades, atributos, relacionamentos e regras de negócio essenciais para o domínio do problema.
